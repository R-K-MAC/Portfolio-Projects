## Experiment Mockup for Proposed Extension of Research Investigating Response Modalities in Line Charts

This repository hosts a static HTML mockup built during a research scholarship. It serves as a live, interactive supplement to a research report and proposal.

**[Click Here to View the Interactive Mockup](https://<YOUR-USERNAME>.github.io/<YOUR-REPO-NAME>/<YOUR-FOLDER-NAME>/)**

This mockup was created as a communication tool to demonstrate a proposed extension of existing data visualization research. Instead of just describing a user interface in my written report, I built this functional layout to visually demonstrate how alternative response modalities would look and behave for participants in a live study.

### Key Focus Areas of the Research:
Grounded in a literature review covering ensemble encoding (including Cindy Xiong Bearfield’s work), visual reasoning strategies, and cognitive load/disfluency theory. Its aim was to build directly upon hypotheses raised in the *'Show or Tell'* papers and *'Local and Global Extrema and Recall Response Modalities Bias Position Recall in Line Charts'* (Xiong Bearfield et al). It was developed alongside full study documentation, including a drafted Explanatory Statement covering participant ethics, consent protocols, and data confidentiality management.

### Technical Details
* Built With plain HTML, CSS, and JavaScript.
* Written and structured in Visual Studio Code.
* Hosted via GitHub Pages to provide a perpetual link for academic and professional review.
